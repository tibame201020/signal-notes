# 台股買入價篩選｜每日獨立研究規範

## 目的與截稿
台灣時間 05:00 發布第七類每日前沿「台股買入價篩選」。文章並非公司布局的重述，而是從台股交易母體建立有來源、有流動性門檻、有可重算價格公式的候選。凍結於截稿前可得資訊；不得將截稿後的美股、台股、財報或其他資訊回填為當時預測。若延後補刊，須同時標示「分析基準日」「實際補刊日」。不限候選產業，不預設昨日推薦續留。不能用來源為美元報價的公司市值快照冒充台灣證交所新台幣收盤價。

## 第一層：資料與流動性
使用證交所、櫃買中心的官方日行情：交易日、股票名稱和代碼、開高低收、成交股數與成交金額；另核對停復牌、除權息或特殊交易。前一交易日成交金額至少新台幣 1 億元、近二十個「有效交易日」平均成交金額至少新台幣 1 億元；兩者都必須實際計算並附交易日區間。缺一不得標為正式通過。禁止只用市值、單日交易量或美元換算價代替成交金額。上市／上櫃資料源與時間分開。

## 第二層：獨立方法交叉
1. 基本面：從公告的季度財報、月營收、法說求獲利品質、成長和自由現金流；事實與假設分開。
2. 估值：用正式財報 EPS、FCF、淨負債等，在可比前提下計算保守／基準／樂觀價位。無法核實輸入時，不把技術價偽稱合理價值。
3. 價格／波動：以前一有效交易日的價格、20／60 日均線、20／60 日價格分位、可回算 ATR(14) 與支撐區推導掛價帶。資料不足可另列短窗情境，但不能稱 14 日 ATR 或 20 日均線。
4. 跨市傳導：美國、台灣、日本、韓國於截稿前已收市且可得的指數、產業指標、匯率與債率，以同口徑觀測日作壓力情境；不把同一半導體風險重複投票。
5. 訊號排序：財務證據、估值落差、量價與觸價可能性、下行條件，候選品質不足當天可無正式推薦。

## 輸出與可核驗格式
研究資料：`data/investment/entry-screenings/YYYY-MM-DD.json`；文章：`src/content/posts/daily-stock-prices-YYYY-MM-DD/index.md`，分類顯示名「每日前沿」、slug `daily-digest`，標籤顯示名「台股買入價篩選」、slug `stock-prices`。

逐股至少列公司及代碼、行情觀測日、昨日收盤價（新台幣）、成交股數和成交金額、近 20 日平均成交金額及計算區間、建議觀察買入價區間（新台幣）、距昨日收盤折價率、公式與參數、保守／基準／樂觀估值或缺失原因、觸價的情境及時間窗、反證條件與來源 URL。明確分為「昨日已達價格」與「未達但合理情境可能觸及」。對缺資料但值得追蹤者另列「待核實觀察」，不得混入正式入選名單。補刊不做事後命中率美化。

## 發布驗收
文章使用臺灣繁體中文，並遵守 `docs/content-language.md`。研究資料須能重算價格與成交金額門檻；新增自動化測試時加入既有 GitHub Pages 建置門檻，執行既有五項測試／驗證與建置。測試或部署未完成不宣稱已刊。
