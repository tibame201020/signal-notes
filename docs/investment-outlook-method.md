# Investment Outlook｜獨立研究規範

## 來源先於候選

每日從六篇「每日前沿」（國際、財經、AI、半導體、Software、金流與估值）和已公開的「我的論點」出發。這兩類是研究輸入。另以交易所、公司公告、財報與技術文件核對推論、價格與估值。

**嚴禁從最近聊天舉的產品／公司、昨天的入選公司、舊投資文章預先產生今日候選名單。** 它們不構成選股指令，也不能改寫使用者已公開的信念。完成今天的獨立排名後，才回看歷史以比較留存／淘汰理由。

## 每日程序

1. **凍結前沿證據。** 先讀六篇當期前沿，寫下高重要性訊號、原始來源、觀測日期與不確定性；另擷取已發表的長期論點。論點不是需要每天驗證的待測假說，且不要求每條前沿都對應 Agent。
2. **需求傳導。** 從訊號推導增量使用量、資本支出或成本結構，再推導誰可以捕捉收入和毛利。搜尋所有合理價值鏈位置：CPU/GPU、DRAM/HBM、SSD、網路、供電、散熱、製造、材料、資料、軟體、資安、服務等；類別僅是可能方向，沒有固定軟硬體名額。
3. **先建候選池。** 原則上初篩至少四家公司，盡量橫跨兩種以上價值鏈和多個前沿訊號；台灣上市櫃優先。每個候選必須能指出由哪項當日訊號衍生，並記錄篩掉的理由。沒有可查資料時可以只研究產業，仍盡可能給一兩家台灣具名觀察標的。
4. **市場 vs 自行估值。** 查有日期的股價、市值、EV、營收/EPS/FCF、財報與指引。釐清市場已反映的成長，使用合理模型建保守／基準／樂觀情境，換算股權價格差距，說明關鍵反證、週期、利潤率及稀釋。「產品需求會增加」不等於「企業利潤會增加」，更不等於「市場低估」。
5. **排序才選股。** 以證據可信度、增量獲利捕捉度、估值差、催化時點、財務品質與下行風險排序，最多挑兩家公司。不要求一硬一軟，也不因前次討論偏向其中一側。
6. **技能投資獨立處理。** 同樣從當日六類前沿尋找稀缺能力需求，最多兩項；明列深入技術、2–4 週投入、可展示作品與驗收指標，而非只依賴最近一次聊天的專案。
7. **最後才比較昨日。** 完成候選池與排名後才查舊投資文章，註記 thesis 改變、留存／淘汰理由，不反向挑新聞替舊名單辯護。

## 每日資料血緣

從 2026-10-09 起，公司文章發布前新增 data/investment/screenings/YYYY-MM-DD.json：

- date：當日台北日期；sourcePosts：六篇當日 daily slug；beliefPosts：已發表論點的 slug。
- signals：id、來自當日哪篇 post、具體 claim、原始 sourceUrls；至少兩個不同每日前沿類別的訊號。
- candidates：company、ticker、market、valueLayer、signalIds、disposition（selected / watch / rejected）、reason；通常研究四家以上與兩個以上價值鏈位置。
- valuation：marketAsOf、method、anchorPrice、currency、bear、base、bull；資料不完整就填 missingValuationReason，不虛構價格。
- rankedIds：所有候選的排序；selectionMode 為 company 或 industry；退回產業時記錄 industryReason、最多兩家具名 watchCompanies。
- 若受可信資料限制不足四家或只涉及一層，保留 limitedPoolReason，不因格式要求編造。

公司篇需有「候選池與淘汰理由」、「市場估值與我的估值」、「推論與選擇」三節。讀者要能看出未入選的是誰、原因為何，以及所選公司是否真的比其他層有較大的估值落差。

過往 2026-10-08 文章保留為舊方法的歷史稿，不追認為已依新流程完成跨軟硬體／產業的獨立比較。新流程自 2026-10-09 啟用。數據證據必須核實，但不需要泛泛的「非投資建議」預防性段落。
