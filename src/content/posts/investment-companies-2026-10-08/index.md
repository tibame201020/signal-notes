## 核心論點：先找企業 Agent 的第二層受益者

我的長期判斷是：當 Agent 可以交換訊息、分工、委派工具，群體行為會逐步出現。這讓企業導入 AI 不再只是模型能力問題，而會變成「**誰控制資料與權限、誰負責連續運作**」的問題。[我的原始論點](https://tibame201020.github.io/signal-notes/articles/huggingface-agent-civilization/) 與 [10/08 Software 前沿](https://tibame201020.github.io/signal-notes/articles/daily-software-2026-10-08/) 是本篇的起點。

相較已經受到市場高度關注的晶片設計、先進製程和大型雲平台，我優先找台灣既有企業客戶、能提供工作流程或資安服務、但還未以 Agent 平台估值的公司。

**本期選擇：安碁資訊（6690）與叡揚資訊（6752）。** 我對安碁的信心在於其多 Agent 服務已進入資安維運與商業推廣；對叡揚的信心在於持續增加的訂閱式收入，以及它掌握企業知識與工作流程入口。兩者的 AI 收入目前都還不足以單獨拆算，估值因此採用本益比情境法，並以公開財務數字校正。

## 1. 安碁資訊（6690）｜多 Agent SOC 可否帶來第二條收入曲線？

### 市場可能漏看什麼

安碁目前主要被視為台灣資安監控委外（MSSP）與顧問服務公司。它已有金融、政府與企業客戶基礎；對我的論點更關鍵的是，安碁已把**多 Agent 架構**部署進 Cloud SOC 的警報分流、威脅獵捕與事件分析流程，並開始向企業推廣代理式資安服務。

根據 2026 年 7 月的 iThome 深入報導，安碁自研 CyberSage、安答（Anda）系統；其 Agent 將進行警報分流、威脅獵捕及自動化回應，並已出現鋼鐵及海運業的概念驗證。這不是我根據 AI 熱潮隨意聯想的受益者，而是**已有交付場景的台灣服務公司**。[iThome｜安碁多 Agent 架構](https://www.ithome.com.tw/news/177707)；[安碁官方網站](https://www.acercsi.com/tw/index)。

**推論：** 若 Agent 能讓同一組 SOC 人力監控更多客戶、降低單一事件處理成本，效益不只反映在新銷售，也可能反映在服務毛利率。這是我關注它而不是泛稱「所有資安股都受惠」的原因。

### 我自己的估值

我以 **未來十二個月 EPS × 合理本益比** 建立三個情境，直接與 178 元市場價格比較。以下 EPS、估值倍數是我的推估；市場已公布的 10.95 元近四季 EPS 是計算起點。

| 情境 | 我估的未來 EPS | 合理本益比 | 情境價格 | 對 178 元差距 |
| --- | ---: | ---: | ---: | ---: |
| 保守：新業務不增利、傳統專案競爭 | 10.0 | 14× | **140 元** | **−21.3%** |
| 基準：維持溫和成長、服務效率改善 | 11.5 | 19× | **218.5 元** | **+22.8%** |
| 樂觀：Agent SOC 轉為高附加價值收入 | 12.5 | 22× | **275 元** | **+54.5%** |

基準情境需要兩個條件同時成立：獲利由 10.95 成長至約 11.5 元，且市場願意由 16.3 倍提高到 19 倍。這並非只靠 EPS 自然成長就能得到的差距。

**布局意見：** 我把安碁放在優先研究的台灣 Agent 企業服務名單。要看下一季新簽約金額是否落入可持續營收，且 SOC 導入 AI 後能否改善毛利，而不是只看客戶 PoC 數量。若 AI 導入成本先壓低毛利，應降低合理本益比。

## 2. 叡揚資訊（6752）｜企業知識庫會不會變成 Agent 的可信上下文？

### 可能低估的價值

叡揚有企業軟體、知識管理、簽核、表單與雲端服務。它的 **Vital Knowledge** 可以管理、分類、檢索企業文件，並提供與 LLM 整合的智能生成模組。若 Agent 在企業內部大量執行工作，企業最常需要的不是再訓練模型，而是把它接上**有持續維護和內部流程脈絡的資料**。[叡揚 Vital Knowledge 官方產品資料](https://www.vitalyun.com/tw/vital-knowledge)。

這個類比更接近「台灣本土企業知識入口」，而不是另一家模型供應商。要注意其現有產品提供的是知識管理與問答；Agent 大規模調用是否能真正提高訂閱單價，仍須觀察產品更新與客戶實際採用。

### 已經有的收入訊號

叡揚 2026 上半年營收約 **9.88 億元、年增 4.47%**；但訂閱式收入約 **4.12 億元、年增 20.56%**，訂閱占比達 **41.73%**。這顯示企業持續從專案授權向訂閱模式轉型，**不是**說整家公司的收入已經以 20% 成長。[叡揚 2026/09 法說簡報整理](https://finmoconf.diveinvest.net/presentation/6a9d7694a16a75b813c911d8)；[中央社 9/02 法說報導](https://www.cna.com.tw/news/afe/202609020348.aspx)。

### 我的估值情境

同樣以未來十二個月 EPS × 情境本益比估計：

| 情境 | 我估的未來 EPS | 本益比 | 情境價格 | 對 96.70 元差距 |
| --- | ---: | ---: | ---: | ---: |
| 保守：政府標案與專案毛利持續受壓 | 5.8 | 12× | **69.6 元** | **−28.0%** |
| 基準：訂閱成長部分轉為獲利 | 7.2 | 17× | **122.4 元** | **+26.6%** |
| 樂觀：企業 Agent 知識層提升客單價 | 8.3 | 20× | **166 元** | **+71.7%** |

我的看法：**叡揚可能比高關注度的 AI 基礎設施股更容易出現認知差。** 目前市場給它約 14 倍本益比，但訂閱式收入正以超過整體公司的速度增長。估值重估需要證明「訂閱式收入增加」能轉化成「EPS 連續上升」，如果毛利率與費用率持續惡化，就應回到保守情境。

## 3. 兩家公司怎麼排序？

| 比較 | 安碁資訊 6690 | 叡揚資訊 6752 |
| --- | --- | --- |
| 與群體 Agent 的關聯 | **直接：** 已導入多 Agent SOC | **間接：** 知識庫可能成為企業 Agent 上下文 |
| 今日估值（近四季本益比） | 16.26× | 14.1× |
| 我估的基準價格 | 218.5 元 | 122.4 元 |
| 主要重估條件 | AI SOC 的服務毛利／簽約轉營收 | 訂閱收入成長帶動 EPS |
| 優先觀察 | 新簽約、毛利率、Agent 業務滲透 | 訂閱占比、獲利率、政府專案進度 |

**本期優先序：安碁排第一，叡揚排第二。** 安碁直接落地多 Agent；叡揚的價值在訂閱式收入與企業知識層。前者要看 AI 實際改善服務效率，後者要看訂閱利潤。這比只盯著台灣大型半導體權值股，更接近你所相信的下一波 Agent 群體協作產業發展。
